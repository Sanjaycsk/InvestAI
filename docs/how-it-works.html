01What it actually does

One disciplined job, every morning before the market opens.

Decide

A verdict per instrument

For each of 24 fixed instruments it produces a BUY / HOLD / SELL call, a 0–100 conviction score, and a one-line reason — grounded in six independent factors.

Grade

Marks its own homework

The next morning it pulls the actual closing prices, checks whether each prior call was right, and computes an accuracy % and a self-rating out of 100.

Learn

Improves over time

It separates correctable mistakes (it misread the data) from market noise (a sound call the market moved against), and carries the lessons into the next day.

It is a research assistant, not a trader. It only suggests — a human makes every decision. Nothing is bought or sold automatically.

02The architecture

Four cooperating environments, each chosen because of where data is actually reachable. The brain runs in Anthropic's cloud; a small home job feeds it the one data source the cloud can't reach.

Home PC · residential IPYouTube Transcript Fetcher
A small scheduled job pulls the latest transcripts from trusted stock-analysis YouTube channels. Why here: YouTube blocks transcript access from datacenter IPs, but allows it from a home connection. Runs automatically each morning (wakes the PC from sleep), then pushes the data out.
Public GitHubData & Code Repository
Holds the transcript data file (read by the cloud) and the version-controlled agent definition — the exact instructions the AI follows. Anyone can audit how the agent is told to think; every change is tracked in git history.
Anthropic Cloud · the brainClaude Agent (daily)
A scheduled Claude agent that runs three times every trading day. The 08:30 pre-market run is the verdict of record — it reads the YouTube data, researches the live web, runs the six-factor analysis on all 24 instruments, grades yesterday, and writes results to memory. Two lighter runs (10:00 confirm, 15:00 de-risk) re-check and protect those calls without ever changing them. Why here: reliable, datacenter-grade access to the web and to Claude's reasoning — and it runs unattended.
Notion · the memoryAuditable Database
Three databases — Recommendations (every call + the reasoning behind each factor, plus the intraday annotations), Daily Review (accuracy, self-rating, mistakes, lessons, and the de-risk "management alpha"), and Coffee Shop (a six-persona debate logged at each run). This is the permanent, human-readable audit trail that makes the agent accountable.
Phone / Web · the dashboardMobile Dashboard (PWA)
A passcode-protected mobile app that reads the Notion databases live and surfaces the day at a glance — today's Buy / Sell / Hold calls as expandable sections, how each fared through the day, what was de-risked before the close, a market-sentiment gauge, a Gold & Silver panel, the accuracy trend with a 1-year backtest, yesterday's graded results, and a Coffee Shop tab where six personas debate the shortlist. Why here: deployed as a cloud web app (installable on the home screen) so it's available anywhere, even when the home PC is off — while the Notion key stays server-side, never exposed to the browser.

Design principle: each layer is independent and replaceable. The data feed, the reasoning, and the memory never depend on each other's internals — only on a shared, documented contract.

03How it uses Claude

The agent is Claude — Anthropic's frontier reasoning model — not a hard-coded script of if/else rules.

Reasoning, not rules

Traditional screeners apply fixed formulas. Here, Claude reads live data and reasons about it the way an analyst would — weighing conflicting signals, judging context, and explaining itself in plain language.

Agentic & tool-using

Claude autonomously decides what to research, runs web searches, fetches financial pages, reads the YouTube transcripts, and writes to the database — a multi-step loop, not a single answer.

Professional methodology built in

The analysis uses sector-appropriate metrics (e.g. ROE / asset-quality for banks, order-book / ROCE for industrials) and relative valuation against peers — methodology harvested from Anthropic's own financial-analysis toolkit.

Self-critique

Because it's a reasoning model, it can do something a formula can't: look back at its own past calls, judge what went wrong, and adjust — a genuine feedback loop.

Model: Claude Sonnet 4.6. It runs on a managed Claude plan — there is no separate API key or per-call billing to manage.

04The daily rhythm — three runs

One verdict per day, set in the morning and then watched over. Trading days only (Mon–Fri), with an NSE-holiday gate.

08:30 · Pre-market

The verdict of record

Grades yesterday, learns from it, analyses all 24, issues today's BUY / HOLD / SELL — then freezes it. The only run that sets the call.

10:00 · Confirm

Re-check after the open

Pulls intraday prices and confirms each thesis still holds, annotating the row. It never changes the frozen verdict.

15:00 · De-risk

Protect before the close

Exits or trims only a position whose thesis has materially broken — graded the next morning as "management alpha".

Inside the pre-market run — the one that decides

Review & grade yesterday

Pull each pending call, read the actual closing price, mark it Correct or Wrong, and compute accuracy % + a self-rating out of 100 — and separately score how well the prior day's 15:00 de-risk run protected capital.

Learn from past reviews

Read the last ~5 days of lessons. Treat correctable mistakes as standing rules it must not repeat today. Leave genuine market-driven misses alone.

Analyze today — all 24

Score six factors (below), combine them with weights tuned to each instrument type, and apply yesterday's corrections.

Decide, log & freeze

Map each composite score to a category and a BUY / HOLD / SELL verdict, write it to Notion with the reasoning for every factor, and freeze it as the day's verdict of record — ready to be graded tomorrow.

05The scoring framework

Six independent factors, weighted by what actually matters for each instrument type. One signal never decides alone, and Risk can veto everything.

FactorWhat it measuresEquity weight
FundamentalSector-appropriate quality: growth, margins, ROE/ROCE, balance sheet, cash flow30%
TechnicalTrend, 50/200-day moving averages, RSI, MACD, support/resistance, volume20%
ValuationP/E, EV/EBITDA, PEG vs sector peers (quartiles) and the stock's own history20%
MacroRates, currency, oil, policy, geopolitics relevant to the sector15%
SentimentTrusted YouTube analysts + news (lowest weight by design)5%
RiskConcentration, drawdown, volatility, event risk — has veto power10%

Fundamentals don't apply to the ETFs, so they use different weightings: the index ETF leans Macro 40 / Technical 35 / Valuation 15 / Sentiment 10, and the Gold & Silver ETFs lean Technical 35 / Macro 30 / Sentiment 25 / Risk 10 — where trusted-analyst sentiment carries real signal.

08Why you can trust it

Trust here doesn't rest on "the AI said so." It rests on accountability you can verify.

It is held accountable, daily verifiable

Every single call is checked against the real closing price the next day and scored. The accuracy track record is recorded — wins and losses — not cherry-picked.

Every decision is logged auditable

Each recommendation is stored in Notion with the reasoning behind all six factors, a timestamp, and the sources used. Nothing is ephemeral; you can scroll back through every call it ever made.

It learns from its mistakes improving

Errors are classified as fixable (analysis flaws) or unavoidable (market surprises). The fixable ones become rules it explicitly applies the next day — and you can see which lessons it used.

No black box transparent

The exact instructions the agent follows are version-controlled in git. Anyone can read precisely how it is told to analyse — and review every change ever made to its method.

Multiple independent factors balanced

No single tip or headline drives a verdict. Six separate evidence streams are weighted, and a dedicated Risk check can veto an over-eager call.

Human always decides by design

The agent never places a trade. It produces research; a person reviews it and acts. The blast radius of any single bad call is, by construction, zero.

10Honest limitations

Being upfront about what it can't do is part of why the rest can be trusted.

  • Markets are uncertain. Even a perfectly reasoned call can be wrong — that's why every call is graded and "market-driven misses" are treated as acceptable, not hidden.
  • No private or insider data. It uses only public web data and public analyst commentary. It cannot see what the market doesn't.
  • One verdict per day, watched intraday. The morning call is set once and frozen — not a high-frequency or live-tick system. The 10:00 and 15:00 runs only monitor and de-risk it; they never issue new verdicts.
  • The dashboard mirrors the agent, not the market. Its sentiment gauge and paper-profit tally are derived from the agent's own calls. The 1-year backtest is of a simpler rule-based proxy, not the full AI — treat it as indicative, not a promise.
  • Not financial advice. It is a research and education tool. Always do your own due diligence; a human makes the final decision.
